# Security Policy

## Supported Versions

Currently, only the latest version is supported.

| Version | Supported |
| ------- | --------- |
| 1.0.0   | ✅         |

## Reporting a Vulnerability

If you discover a security vulnerability in Velkor, please report it privately by sending an email to the address listed on my GitHub profile.

Please include:

* A clear description of the vulnerability.
* Steps to reproduce the issue.
* The potential impact.
* Any suggested fix (if available).

Please **do not** disclose security vulnerabilities publicly until they have been reviewed and addressed.

Thank you for helping keep Velkor secure!
