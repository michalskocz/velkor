# Contributing to Velkor

Thank you for your interest in contributing to Velkor!

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear commit message.
5. Open a Pull Request describing your changes.

## Reporting Issues

If you find a bug or have a feature request, please open a GitHub Issue with:

* A clear title.
* A detailed description.
* Steps to reproduce (for bugs).
* Expected and actual behavior.

## Code Style

* Keep the code clean and readable.
* Follow the existing project style.
* Add comments only when they improve understanding.
* Test your changes before submitting.

## Pull Requests

Before opening a Pull Request, make sure:

* Your code builds successfully.
* Existing functionality is not broken.
* Your changes are focused on a single feature or fix.
* You have updated documentation if necessary.

Thank you for helping improve Velkor!
